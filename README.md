# ✌️ تشخیص علامت پیروزی با استفاده از حرکات دست (Hand Gesture Recognition)

این پروژه با استفاده از کتابخانه‌های **OpenCV** و **MediaPipe**، حرکات دست را به‌صورت زنده از طریق وب‌کم تشخیص می‌دهد و مشخص می‌کند که آیا کاربر علامت پیروزی (✌️) را با دست خود نشان داده است یا خیر.

## 🚀 امکانات پروژه

- تشخیص دست به‌صورت زنده با استفاده از وب‌کم
- شناسایی نقاط کلیدی دست با استفاده از MediaPipe
- بررسی وضعیت انگشتان برای تشخیص علامت پیروزی
- نمایش نتیجه تشخیص روی تصویر وب‌کم
- ذخیره خودکار تصویر هنگام تشخیص علامت پیروزی

## 🛠️ ابزارها و کتابخانه‌های استفاده‌شده

- Python
- OpenCV
- MediaPipe

## ▶️ نحوه اجرا

برای اجرای پروژه دستور زیر را وارد کنید:

```bash
python main.py
```

پس از اجرا:

1. وب‌کم سیستم فعال می‌شود.
2. دست خود را مقابل دوربین قرار دهید.
3. علامت پیروزی (✌️) را با دست نشان دهید.
4. در صورت تشخیص علامت، عبارت `VICTORY` روی تصویر نمایش داده می‌شود.
5. در غیر این صورت عبارت `NOT VICTORY` نمایش داده خواهد شد.
6. هنگام تشخیص علامت پیروزی، یک تصویر با نام `screen.png` ذخیره می‌شود.

برای خروج از برنامه کلید `q` را فشار دهید.

## 📸 خروجی پروژه

در صورت تشخیص علامت پیروزی:

```text
VICTORY
```

در صورت تشخیص ندادن علامت:

```text
NOT VICTORY
```

همچنین تصویر ثبت‌شده در فایل `screen.png` ذخیره می‌شود.

## 🧠 نحوه عملکرد برنامه

1. دریافت تصویر زنده از وب‌کم با استفاده از OpenCV
2. تبدیل فضای رنگی تصویر از BGR به RGB
3. پردازش تصویر با استفاده از MediaPipe Hands
4. استخراج نقاط کلیدی انگشتان دست
5. بررسی موقعیت انگشتان و تشخیص حالت آن‌ها
6. تشخیص علامت پیروزی بر اساس شرایط تعریف‌شده
7. نمایش نتیجه و ذخیره تصویر در صورت تشخیص موفق

- استفاده از حرکات دست برای کنترل کامپیوتر
